# 관리자 대시보드 구상

> 구상일: 2026-07-30 | 상태: 구상 (미구현)

---

## 핵심 화면 (4개)

| 화면 | 기능 | Admin API |
|------|------|-----------|
| **사용자 검색** | 닉네임/이메일 검색 → 상세 정보 + 재화 원장 | `GET /admin/users`, `GET /admin/users/:id` |
| **계정 제재** | 정지/해제 + 사유 입력 | `PUT /admin/users/:id/suspend`, `/unsuspend` |
| **재화 지급** | 사용자 선택 → electricity/scrap 수량 → 사유 → 지급 | `POST /admin/users/:id/grants` |
| **간단 대시보드** | 총 가입자, 오늘 제재, 최근 지급 목록 | `GET /admin/users`, `GET /admin/grants` |

## 기술 스택

```
React + Vite + Tailwind CSS + React Query
```
