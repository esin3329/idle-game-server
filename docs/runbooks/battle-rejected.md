# 전투 결과 거절 확인

## 서버 검증 기록

거절 코드, 전투 세션 상태, 서버가 저장한 처치 수와 Core Energy, 이벤트 시각을 비교한다. 요청 본문에 있는 누적 값만으로 정당성을 결론 내리지 않는다.

## 주요 확인 항목

- `TIME_OUT_OF_RANGE`: 스테이지 제한 시간과 보고된 경과 시간 확인.
- `FINAL_KILLS_MISMATCH`: 서버 누적 처치 수와 종료 보고 비교.
- `CORE_ENERGY_MISMATCH`: 서버 기록과 종료 보고 비교.
- `BOSS_MISMATCH`: 세션에서 확인된 보스 처치와 종료 보고 비교.
- `PENDING_UPGRADES`: 선택 대기 중인 강화가 남았는지 확인.

## 운영자 대응

전투 거절 코드를 사용자에게 설명하고, 불일치가 반복되면 세션과 이벤트 ID를 보존해 게임 서버 담당자에게 전달한다. AI는 세션 상태를 바꾸거나 보상을 확정하지 않는다.
