# 보상 누락 확인

## 지급이 실제로 반영됐는지

`currency_ledger`에서 문의 시간 주변의 거래를 확인한다. `amount`와 `balanceAfter`가 실제 지급 여부를 보여준다. 같은 요청 재전송은 같은 멱등성 키의 기록과 연결되어야 한다.

## 방치 보상

방치 보상은 서버의 마지막 수령 시각과 초당 생산량을 기준으로 계산되며 최대 8시간까지만 누적된다. 클라이언트 시각은 판정 근거가 아니다. 마지막 수령 시각과 원장의 `idle_claim` 항목을 함께 확인한다.

## 운영자 대응

원장 기록이 없으면 지급이 완료됐다고 안내하지 않는다. 계정·시각·재화 종류를 확인하고 서버 기록이 불완전하면 게임 서버 담당자에게 전달한다. 추가 지급은 운영자가 기존 지급 화면에서 중복 여부를 확인한 뒤 별도 권한으로 결정한다.
